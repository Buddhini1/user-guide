Business Loan User Guide

1. Master Data Setup (Admin)

⚠️
Note: These master data setup steps must be completed before moving to the next stages of the system process.

1.1 Create Charge Types

Path: Admin → Loan → Charge Type
  • Create loan charge types.
  • Add all charges related to micro loans.

1.2 Create Loan Periods

Path: Admin → Loan → Periods
  • Configure loan periods.
  • Add all periods related to micro loans.

1.3 Create Villages

Path: Admin → Common → Villages
  • Prerequisite: Before creating a village, the user must first set up the geographical hierarchy under Admin → Common :
    1. Province
    2. District
    3. DSD
    4. GND
    5. Branch
  • Creating villages is essential, as they are required when creating Centers (step 3.2) in subsequent loan creation steps.

1.4 Create Titles, Main Sector, Sub Sector, Sector, Education and Relationship

Path: Admin → Common
  • Configure administrative lookup data including Main Sector, Sub Sector, Sector, Education, and Relationship .
  • These configurations are necessary for the customer creation and loan application processes.

1.5 Create Cashier

Path: Admin → Common → Cashier
  • Create cashier accounts.

1.6 Mapping GL Accounts

Paths:
1. Admin → Finance → Notes
2. Admin → Finance → Finance GL Mapping
3. Admin → Finance → Finance Report GL Mapping
  • Configure General Ledger (GL) account mappings.
  • User should map the system across all three financial mapping interfaces.

2. Customer Creation

2.1 Create Customers

Path: Customer Module → Customers
  • Creation of clients of the business.
  • Create a minimum of 3 customers for the business loan including the loan borrower. In addition to the loan borrower, all guarantors related to the loan borrower need to be added from here as customers.
  • For a Business Loan, minimum 1 to maximum 2 guarantors can be added per loan.

3. Loan Creation

3.1 Create Loan Product

Path: Business Loan → Products → Products
⚠️
Important: Please map GL Accounts on the product form before starting the loan process to keep the system running smoothly and prevent system errors.
  • Prerequisite: Step 1.1 (Charge Types) and Step 1.2 (Loan Periods) must be fully completed prior to creating a product.

3.2 Create Route

Path: Business Loan → Operation → Route
  • Prerequisite: Step 1.3 (Villages) must be completed before creating a Route.
  • Create a Route before starting the loan application process.

3.3 Add FDO to Routes

Path: Business Loan → Operation → Add/Change FDO
  • Prerequisite: Step 3.2 (Route) and FDO user must be created.

    To create an FDO user, go through: Admin → Common → Users
    Note: Make sure to select FDO as the designation type for FDO users.

3.4 Create Family Details

Path: Business Loan → Application → Customer Family Details
  • Create family details for all 3 customers (for loan borrower and related guarantors).
  • All customers and their family members must be mapped to the same branch .

3.5 Create Credit Evaluation

Path: Business Loan → Application → Credit Evaluation
  • Complete the credit evaluation for the customer (loan borrower).

3.6 Create Guarantor Detail

Path: Business Loan → Application → Guarantor Detail
  • Create 1 or 2 guarantors for a loan facility.

3.7 Create PDC Security

Path: Business Loan → Application → Guarantor Detail
  • This step is optional.

3.8 Create Facility (Loan)

Path: Business Loan → Application → Facility
  • Create the loan facility for the customer (borrower).

4. Loan Approval Process

4.1 Verify Loan Details

Path: Business Loan → Operation → Verification

4.2 HOO Approval Process

Path: Business Loan → Operation → HOO Approval

5. Charge Payment

5.1 Create Cash Register

Path: Cashier → Cash Register

Extra Note: If the previous day's cashier is not closed, please do denomination. Then open a new Cash Register for a new day.
For more details, refer to the Cashier Module document.

5.2 Pay Facility Charges

Path: Cashier → Business Loan → Facility Charges

6. Loan Activation

  • To activate a loan, the system user must be logged into the same branch as the customer.

    For example, if the customer belongs to the Matara branch, only a user logged into the Matara branch can activate that loan.

6.1 Credit Approval

Path: Business Loan → Finance → Credit Approval

6.2 Activate Facility

Path: Business Loan → Finance → Activate Facility
  • From the dropdown, select the related batch number to activate.

Process Flow Summary

  1. Setup Master Data
  2. Create Customers (Borrower and Guarantors)
  3. Create Loan Product
  4. Create Family Details (Map customers & families to the same branch)
  5. Create Credit Evaluation for each Customer (Borrower & Guarantors)
  6. Create Loan Facility for Customer
  7. Verify Loan Details
  8. HOO Approval
  9. Create Cash Register
  10. Pay Facility Charges
  11. Credit Approval
  12. Activate Loan Facility
