Cashier Operations & Repayments User Guide

1. Open Cashier

Note: User needs to add a cashier before opening a cashier session. Go to Admin → Common → Cashier to configure it first.

1.1 Cash Register & Open Cashier

Path: Cashier → Cash Register

1.2 Cashier Top-up

Path: Admin → Common → Cashier Topup
  • Top-up cashier with cash (Cash in Hand).

1.2 Mapping GL Accounts

Paths:
1. Admin → Finance → Notes
2. Admin → Finance → Finance GL Mapping
3. Admin → Finance → Finance Report GL Mapping
  • Configure General Ledger (GL) account mappings before making payments.

1.3 Create Bank Accounts

Paths:
1. Add Banks - Admin → Finance → Bank
2. Add bank branches - Admin → Finance → Bank Branches
3. Add Bank accounts - Admin → Finance →Bank Accounts
4. Add Cheque books - Admin → Finance → Cheque Book Register
  • To make payments using bank account or cheques this configuration Requires.

2. Loan Repayment

  • Micro Loan Repayment: Path: Cashier → Micro Loan → Repayment
  • Business Loan Repayment: Path: Cashier → Business Loan → Repayment
  • Lease Repayment: Path: Cashier → Leasing → Repayment

3. Payment Cancel

Used to cancel an unwanted or incorrect transaction repayment.

  • Micro Loan Payment Cancel: Path: Cashier → Micro Loan → Payment Cancel
  • Business Loan Payment Cancel: Path: Cashier → Business Loan → Payment Cancel
  • Lease Payment Cancel: Path: Cashier → Leasing → Payment Cancel
⚠️
User needs to approve the payment cancellation from the respective [Micro Loan / Business Loan Module / Lease Module] → Approvals → Payment Cancel

Unless the approval process is officially completed and done, the payment transaction will NOT be cancelled in the system.
Status Processing Rules:
  • If the cancellation is rejected from approval, the payment will not be cancelled.
  • If the cancellation is accepted, then the payment is cancelled.
  • The relevant status (whether Pending, Cancelled, or Rejected) can be viewed from Cashier → [Micro Loan / Business Loan / Lease] → Payment Cancel.

4. Facility Charges

Facility charges are displayed dynamically only after the loan verification process is officially finalized. As the immediate next step following successful loan verification (After Micro Loan/Business Loan → Approvals → HOO), user is required to settle these processing dues.

4.1 Paying Facility Charges

  • Micro Loan Facility Charges: Path: Cashier → Micro Loan → Facility Charges
  • Business Loan Facility Charges: Path: Cashier → Business Loan → Facility Charges
  • Leasing Facility Charges: Path: Cashier → Leasing → Facility Charges

4.2 Facility Charges Cancellation

If a paid facility charge needs to be reversed or cancelled, it must be initiated from the cashier dashboard and routed through authorization rules:

  • Micro Loan Charges Cancel: Path: Cashier → Micro Loan → Charges Cancel
  • Business Loan Charges Cancel: Path: Cashier → Business Loan → Charges Cancel
  • Lease Charges Cancel: Path: Cashier → Leasing → Charges Cancel
⚠️
Once the reversal is applied by the cashier, user must approve it via: [Micro Loan / Business Loan Module / Lease] → Approvals → Charge Cancel Approval.

Unless this systemic approval process is fully finalized, the charge will NOT be cancelled, and the transaction balance remains valid.
Reporting Track: Users can query real-time processing statuses via: [Micro Loan / Business Loan / Lease Module] → Reports → Facility Charges.

5. Default Write Off

Used to initiate and process default write-offs for accounts deemed unrecoverable.

  • Micro Loan Default Write Off: Path: Cashier → Micro Loan → Default Write Off
  • Business Loan Default Write Off: Path: Cashier → Business Loan → Default Write Off
  • Lease Default Write Off: Path: Cashier → Leasing → Default Write Off
Note: Once created from the cashier panel, the request must be approved through the matching core module authorization track: [Micro Loan / Business Loan / Lease Module] → Approvals → Default Write Off.
⚠️
Unless the request is officially approved via the approvals track, the specified amount will NOT be default write-offed from the system. The loan balance remains active until authorized.

6. Insurance Premium (Lease)

This option is available exclusively for lease facilities to process insurance payments.

  • Lease Insurance Premium: Path: Cashier → Leasing → Insurance Premium

7. Pawning Renewal (Pawning)

This option is available exclusively for pawning facilities (Renewal / Part Payment) to handle asset renewals or partial payments.

  • Pawning Renewal / Part Payment: Path: Cashier → Pawning → Renewal

8. Payment Wave Off (Pawning)

Used to initiate and process payment wave-offs specifically for pawning accounts.

  • Pawning Payment Wave Off: Path: Cashier → Pawning → Payment Wave Off
Note: Once created from the cashier panel, the wave off request must be approved through the core pawning module authorization track: Pawning Module → Approvals → Payment Wave Off.

9. Collection Payments

Payments collected through the collection app can be viewed on sync collection data or from the ledger card reports.

  • Micro Loan Sync & Reporting:
    Path 1: Cashier → Micro Loan → Sync Collection Data
    Path 2: Micro Loan → Reports → Ledger Card
  • Business Loan Sync & Reporting:
    Path 1: Cashier → Business Loan → Sync Collection Data
    Path 2: Business Loan → Reports → Ledger Card

10. Cash & Cheques Bank

Used to manage and register direct banking adjustments for cash operations and physical cheques.

  • Cash Bank: Path: Cashier → Cash Bank
  • Cheque Bank: Path: Cashier → Cheques Bank

11. Close Cashier (Denominations)

Path: Cashier → Denomination

The Denomination screen acts as the master financial summary pane where all active running totals—including cash in hand, total cheque values, bank transfers, collections, and miscellaneous adjustments—are captured dynamically.

Mandatory Day End Rule: At the close of business each day, the user must input the physical breakdown of currency counts into the Denomination panel. This action reconciles system-tracked amounts against actual assets and is required to officially close out the daily cashier session.

Process Flow Summary

  1. Setup / Open Cashier (Add Cashier → Input Denominations → Open via Cash Register)
  2. Process Micro / Business / Lease / Pawning Repayments
  3. Manage Payment Cancellations (Requires Module Approvals; Payment remains active until authorized)
  4. Process Default Write Offs (Requires Module Approvals; Amount remains unchanged until authorized)
  5. Sync Collection App Data or View via Module Reports (Ledger Card)
  6. Close Cashier (Denominations)
