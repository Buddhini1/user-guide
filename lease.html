Leasing User Guide

1. Master Data Setup (Admin)

⚠️
Note: These master data setup steps must be completed before moving to the next stages of the system process.

1.1 Create Charge Types

Path: Admin → Loan → Charge Type
  • Create loan charge types.
  • Add all charges related to micro loans.

1.2 Create Lease Periods / Loan Periods

Path: Admin → Loan → Periods
  • Configure loan and lease periods.
  • Add all periods related to the facilities.

1.3 Setup Geographical hierarchy

Path: Admin → Common →
  • Province
  • District
  • DSD
  • GND
  • Branch
  • Village

1.4 Create Titles, Main Sector, Sub Sector, Sector, Education and Relationship

Path: Admin → Common
  • Configure administrative lookup data including Main Sector, Sub Sector, Sector, Education, and Relationship.
  • These configurations are necessary for the customer creation and loan application processes.

1.5 Create Cashier

Path: Admin → Common → Cashier
  • Create cashier accounts.

1.6 Mapping GL Accounts

Paths:
1. Finance → Notes
2. Finance → Finance GL Mapping
3. Finance → Finance Report GL Mapping
  • Configure General Ledger (GL) account mappings.
  • User should map the system across all three financial mapping interfaces.

1.7 Create Vehicle Setup Data

Paths:
1. Admin → Leasing → Vehicle Type
2. Admin → Leasing → Vehicle Make
3. Admin → Leasing → Vehicle Model
  • Configure vehicle specifications from the admin panel.
  • Ensure Make and Model parameters are properly structured under their respective Vehicle Types.

1.8 Create Partner & Operations Registries

Paths:
1. Admin → Leasing → Insurance Company
2. Admin → Leasing → Seizers
3. Admin → Leasing → Valuation Companies
4. Admin → Leasing → Vehicle Yards
5. Admin → Leasing → Auction Companies
  • Register approved external service providers, valuation agencies, and asset recovery entities.
  • These operational setups must be configured from the admin panel before processing leasing workflows.

2. Customer creation (Lessees & Guarantors)

2.1 Create Customers

Path: Customer Module → Customers
  • Creation of clients and guarantors for the leasing profiles.

3. Facility Creation

3.1 Create Facility Product

Path: Leasing → Products → Products
  • Prerequisite: Step 1.1 (Charge Types) and Step 1.2 (Periods) must be fully completed prior to creating a product.

3.2 Supplier creation

Path: Lease → Application → Supplier Details
  • Register dealer or vendor details related to the leased asset under the current application setup.

3.3 Create Family Details

Path: Leasing → Application → Customer Family Details
  • Create family details for all mapped application parties (Borrower/Lessee and related guarantors).
  • All parties and their family profiles must map back to consistent geographical or asset tracking bounds.

3.4 Create Credit Evaluation

Path: Lease → Application → Credit Evaluation
  • Complete the credit evaluation for the customer to assess risk and processing limitations.

3.5 Add Guarantors Detail

Path: Lease → Application → Guarantor
  • Map individual guarantor metrics, liabilities, and link profiles directly to the current application.

3.6 Add Introducers

Path: Lease → Application → Introducer
  • Input sales agent or intermediary profile details who introduced the facility.

3.7 Add vehicle details/ Land details

Path: Lease → Application → Vehicle Details/land Details
  • Select if it's a vehicle or land lease.
  • If land is selected, select and input into Land Details. If vehicle is chosen, select and input into Vehicle Details.

3.8 Facility details

Path: Lease → Application → Facility Details
  • Define calculated rentals, interest parameters, operational terms, and structure breakdowns.

3.9 Create Cheque Defines

Path: Lease → Application → Cheque Defines
  • Configure repayment checklist matrix logs and specific transactional cheque guidelines.

3.10 Create a PDC Security

Path: Lease → Application → PDC Security
  • Register Post-Dated Cheque (PDC) compliance logs, amounts, counts, and security banking paths.

3.11 create CR Updates (optional)

Path: Lease → Application → CR Updates
  • Log additional credit registries or updated financial risk reports where applicable.

4. Facility Approval Process

4.1 Verify Facility Details

Path: Leasing → Operation → Verification

4.2 HOO / Credit Committee Approval

Path: Leasing → Operation → HOO Approval

5. Charge Payment

5.1 Create Cash Register

Path: Cashier → Cash Register
Extra Note: If the previous day's cashier is not closed, please perform denomination steps first. Then, open a new Cash Register for a new day. (For more details, refer to the Cashier Module Document).

5.2 Pay Facility Charges

Path: Cashier → Lease → Facility Charges

6. Loan Activation

⚠️ Crucial Branch Activation Rules:
To activate a loan, the system user must be logged into the same branch as the customer. For example, if the customer belongs to the Matara branch, only a user logged into the Matara branch can activate that loan.

6.1 Credit Approval

Path: Lease → Finance → Credit Approval

6.2 Activate Facility

Path: Lease → Finance → Activate Facility
  • From the dropdown selection, select the related batch number to trigger activation.

Process Flow Summary

  1. Setup Master data
  2. Create Customers
  3. Create Loan Product
  4. Create Supplier
  5. Create Family Details (Map customers & families to the same Center)
  6. Create Credit Evaluation for Customer
  7. Create Guarantors
  8. Create Group Mapping
  9. Create Introducer
  10. Add Vehicle/ land details
  11. Create a cheque define
  12. create PDC and CR updates
  13. Verify Loan Details
  14. HOO Approval
  15. Create Cash Register
  16. Pay Facility Charges
  17. Credit Approval
  18. Activate Loan Facility
