Pawning User Guide

1. Master Data Setup (Admin)

⚠️
Note: These master data setup steps must be completed before moving to the next stages of the system process.

1.1 Create Charge Types

Path: Admin → Loan → Charge Type
  • Create loan charge types.
  • Add all charges related to micro loans and pawning facilities.

1.2 Create Lease Periods / Loan Periods

Path: Admin → Loan → Periods
  • Configure loan maturity and pawning ticket periods.
  • Add all periods related to the facilities.

1.3 Setup Geographical hierarchy

Path: Admin → Common →
  • Province
  • District
  • DSD
  • GND
  • Branch
  • Village

1.4 Create Titles, Main Sector, Sub Sector, Sector, Education and Relationship

Path: Admin → Common
  • Configure administrative lookup data including Main Sector, Sub Sector, Sector, Education, and Relationship.
  • These configurations are necessary for the customer creation and pawning application processes.

1.5 Create Cashier

Path: Admin → Common → Cashier
  • Create cashier accounts.

1.6 Mapping GL Accounts

Paths:
1. Finance → Notes
2. Finance → Finance GL Mapping
3. Finance → Finance Report GL Mapping
  • Configure General Ledger (GL) account mappings.
  • User should map the system across all three financial mapping interfaces for balance sheet and interest processing rules.

1.7 Create Pawning Setup Data

Paths:
1. Admin → Pawning → Pawning Type
2. Admin → Pawning → Pawning Category
3. Admin → Pawning → Pawning Sub Category
4. Admin → Pawning → Pawning KTs
5. Admin → Pawning → Article Condition
6. Admin → Pawning → 24K Gold Price
7. Admin → Pawning → Today Gold Price
  • Configure administrative lookup parameters for handling pawned articles.
  • Establish current gold rate boundaries, purity markers (KTs), and item classifications from the admin screen prior to processing new tickets.

2. Customer creation

2.1 Create Customers

Path: Customer Module → Customers
  • Creation of clients/pawners inside the system profile registry.

3. Facility Creation

3.1 Create Facility Product

Path: Pawning → Products → Products
    ⚠️ Important: Please map GL Accounts on the product form before starting the loan process to keep system running smoothly and prevents system errors.
  • Prerequisite: Step 1.1 (Charge Types) and Step 1.2 (Loan Periods) must be fully completed prior to creating a product.

3.2 Create Loan

Path: Pawning → Application → Loan Create
  • Prerequisite: Step 1.7 (Pawning Setup Data) must be fully completed prior to executing a loan creation entry.

4. Facility Approval Process

4.1 Verify & Approve Facility Details (Tier 1)

Path: Pawning → Approval → Approval - (0 - 499,999)
  • Select this path if the evaluated pawn loan balance falls within the range of 0 to 499,999.

4.2 Verify & Approve Facility Details (Tier 2)

Path: Pawning → Approval → Approval - (500,000 > X)
  • Select this path if the evaluated pawn loan balance is strictly greater than 499,999 (500,000 and above).

5. Loan Activation

⚠️ Crucial Branch Activation Rules:
To activate a loan and execute cash-out updates, the system user must be logged into the same branch as the customer.

5.1 Issue Cash for Loan

Path: Pawning → Operation → Cash Out
  • Finalize the pawn facility verification metrics to release the calculated cash balance directly to the customer.

Process Flow Summary

  1. Setup Master Data (Admin lookup, parameters & financial mappings)
  2. Configure Pawning Setup Data (Types, Categories, KTs, Conditions & Prices)
  3. Create Customers
  4. Create Pawning Facility Product
  5. Execute Pawning Loan Application (Pawning → Application → Loan Create)
  6. Evaluate Loan Range Criteria for Approval Assignment
  7. Process Approval via Tier 1 Box (0 - 499,999) OR Tier 2 Box (500,000 > X)
  8. Perform Branch Validation Check
  9. Execute Loan Cash Out Disbursal (Pawning → Operation → Cash Out)
