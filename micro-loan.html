Micro Loan User Guide

1. Master Data Setup (Admin)

⚠️
Note: These master data setup steps must be completed before moving to the next stages of the system process.

1.1 Create Charge Types

Path: Admin → Loan → Charge Type
  • Create loan charge types.
  • Add all charges related to micro loans.

1.2 Create Loan Periods

Path: Admin → Loan → Periods
  • Configure loan periods.
  • Add all periods related to micro loans.

1.3 Create Villages

Path: Admin → Common → Villages
  • Prerequisite: Before creating a village, the user must first set up the geographical hierarchy under Admin → Common:
    1. Province
    2. District
    3. DSD
    4. GND
    5. Branch
  • Creating villages is essential, as they are required when creating Centers(step 3.2) in subsequent loan creation steps.

1.4 Create Titles, Main Sector, Sub Sector, Sector, Education and Relationship

Path: Admin → Common
  • Configure administrative lookup data including Main Sector, Sub Sector, Sector, Education, and Relationship.
  • These configurations are necessary for the customer creation and loan application processes.

1.5 Create Cashier

Path: Admin → Common → Cashier
  • Create cashier accounts.

1.6 Mapping GL Accounts

Paths:
1. Admin → Finance → Notes
2. Admin → Finance → Finance GL Mapping
3. Admin → Finance → Finance Report GL Mapping
  • Configure General Ledger (GL) account mappings.
  • User should map the system across all three financial mapping interfaces.

2. Customer Creation

2.1 Create Customers

Path: Customer Module → Customers
  • Creation of clients of the business.
  • Create a minimum of 3 customers for the micro loan group including loan borrower.(Addition to loan borrower,all gurantors related to loan borrower need to be added from here as customers.)
  • For a Micro loan min 2 to Max 4 gurantors can be added per Loan group map.

3. Loan Creation

3.1 Create Loan Product

Path: Micro Loan → Products → Products

    ⚠️ Please map GL Accounts on the product form before starting the loan process to keep system running smoothly and prevents system errors.

  • Prerequisite: Step 1.1 (Charge Types) and Step 1.2 (Loan Periods) must be fully completed prior to creating a product.

3.2 Create Center

Path: Micro Loan → Operation → Center
  • Prerequisite: Step 1.3 (Villages) must be completed before creating a Center.
  • Create a Center before starting the loan application process.

3.3 Create Family Details

Path: Micro Loan → Application → Customer Family Details
  • Create family details for all 3 customers.(for Loan borrower and related gurantors)
  • All customers and their family members must be mapped to the same Center.
Important Grouping Rules: Before proceeding with the loan creation process, ensure that at least 3 customers have been created. All selected customers must belong to the same Center and must not already be assigned to another Group Mapping. Only customers who are not mapped to any existing group can be added to a new group.

3.4 Create Credit Evaluation

Path: Micro Loan → Application → Credit Evaluation
  • Complete the credit evaluation for customer.

3.5 Create Facility (Loan)

Path: Micro Loan → Application → Facility
  • Create the loan facility for customer(borrower).

3.6 Create Group Mapping

Path: Micro Loan → Application → Group Mapping
  • Create a new Group Mapping.
  • Select the gurantors who belong to the same Center.
  • Add all gurantors to the group.
  • Save the Group Mapping.

4. Loan Approval Process

4.1 Verify Loan Details

Path: Micro Loan → Operation → Verification

4.2 HOO Approval

Path: Micro Loan → Operation → HOO Approval

5. Charge Payment

5.1 Create Cash Register

Path: Cashier → Cash Register

Extra Note: If previous day cashier is not closed, please do denomination. Then open a new cash Register for a new day. (For more details refer: cashier module documnet)

5.2 Pay Facility Charges

Path: Cashier → Micro Loan → Facility Charges

6. Loan Activation

  • To activate a loan, the system user must be logged into the same branch as the customer.
    For example, if the customer belongs to the Matara branch, only a user logged into the Matara branch can activate that loan.

6.1 Credit Approval

Path: Micro Loan → Finance → Credit Approval

6.2 Activate Facility

Path: Micro Loan → Finance → Activate Facility
  • From dropdown select related batch no. to activate.

Process Flow Summary

  1. Setup Master data
  2. Create Customers (Borrower and Guarantors)
  3. Create Loan Product
  4. Create Center
  5. Create Family Details (Map customers & families to the same Center)
  6. Create Credit Evaluation for each Customer
  7. Create Loan Facility for each Customer
  8. Create Group Mapping
  9. Verify Loan Details
  10. HOO Approval
  11. Create Cash Register
  12. Pay Facility Charges
  13. Credit Approval
  14. Activate Loan Facility
